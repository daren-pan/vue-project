3操作速查表

操作端点操作者 / 条件对流程的影响
发起POST /instance/start申请人注入 applicant / deptLeader / parentDeptLeader / assigneeList_* 变量 → 启动实例，创建首个审批任务
✓ 通过POST /task/approve任务处理人记录评论 → completeTask(approved=true) → 网关判定下一节点；流程结束 → 自动创建抄送任务
批量通过 ● 新增POST /task/batchApprove任务处理人逐条调用 approve；单条失败仅记录「审批失败」，不影响其余任务，结果按入参顺序返回
✕ 驳回POST /task/reject任意审批人记录评论 → 删除整个流程实例；已办历史状态显示「已退回」
↺ 驳回到上一步POST /task/rollback任意审批人changeActivityStateBuilder 把当前节点移回最近已完成节点；已是首节点 → 退化为驳回
＋ 加签POST /task/addSign当前处理人创建独立加签任务（parentTaskId=主任务）；_signCount++、_signOwner=主任务；主任务通过后挂起等待
≡ 会签设计时 assigneeList > 1流程设计者生成并行多实例节点，全部通过才推进（nrOfCompletedInstances == nrOfInstances）
✉ 抄送已阅POST /task/dismiss被抄送人删除抄送任务及历史记录（已阅）；抄送任务在流程结束时由系统自动创建
↩ 撤回POST /instance/{id}/withdraw申请人 · 且无审批记录删除流程实例（deleteReason=申请人撤回）；历史「已撤回」，进入申请人已办列表
⊘ 强制删除POST /task/deleteInstance管理员先清理加签/抄送等孤儿任务，再删除流程实例（管理员强制清理）
待办 / 已办GET /task/todo · /task/history按 assignee 查询待办含加签、抄送任务；已办含「已通过 / 已退回 / 已撤回」
审批轨迹GET /instance/{id}/track—发起 → 各节点（通过 / 驳回 / 加签通过）→ 当前待办（pending）→ 终态，过滤回退产生的中断记录
流程定义管理/definition/*设计者表格配置 ↔ BPMN 互转（deployFromTable / extractConfig）、历史版本列表、applyVersion 克隆重新部署为最新版

4流程定义设计（表格配置 → BPMN）

5节点类型与连线说明

配置字段取值 / 类型作用与生成规则
processKeyString流程唯一标识（如 leave），BPMN process id 与部署 key
processNameString流程名称（如 请假审批），BPMN process name
node.idString节点唯一标识（如 managerApprove）
node.typestartEvent · endEvent · userTask · exclusiveGateway决定生成哪种 BPMN 元素；userTask 是唯一可配置审批人的类型
node.assigneeString单人审批人，支持变量 ${manager} / ${deptLeader} 等，发起时解析注入
node.assigneeListList<String>会签名单：>1 人生成并行多实例（userTaskMulti），=1 人退化为普通 userTask；写入 SIGN: 文档供发起注入
line.fromString连线起点节点 id
line.toString连线终点节点 id
line.conditionString（可选）条件表达式（如 days > 3），排他网关分支据此判定走向
ccUsersList<String>抄送人列表，流程结束自动通知；写入 CC: 文档段

6设计规范说明

要点说明
表格 ↔ BPMN 双向转换deployFromTable（表格 → BPMN 部署）与 extractConfig（BPMN → 表格）互逆，前端以表格形式设计、后端落为 BPMN 定义
会签两种来源设计时通过 assigneeList 配置（BPMN 多实例节点）与运行时 addSign 动态加签（独立任务）是两套独立机制
审批人占位符发起时解析 ${applicant} / ${deptLeader} / ${parentDeptLeader} 注入为流程变量 assigneeList_*；RemoteUserService 解析失败兜底 admin
版本管理每次部署生成新版本；applyVersion 克隆旧版本配置重新部署为最新版，历史版本可查可回退
documentation 段BPMN 流程级 documentation 以 CC:（抄送）与 SIGN:（会签名单）前缀存元数据，发起时解析
